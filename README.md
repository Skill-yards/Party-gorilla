# 🦍 Party Gorillas

A modern, responsive entertainment and event-services website built for **Gorilla Vibes**.

The website showcases gorilla entertainment, event services, decorations, DJ sound, tents, coffee machines, and other celebration services. It is designed with a bold, energetic visual style while remaining clean and easy to navigate.

---

## ✨ Features

- 🎉 Attractive landing/hero sections
- 🦍 Gorilla entertainment packages
- 📦 3 × 3 responsive package/service grid
- 📱 Mobile-first responsive design
- 🖼️ Event memories and gallery
- 🎥 Support for both images and videos in the gallery
- 🔍 Full-screen gallery lightbox
- ⬅️ Previous / next gallery navigation
- ⌨️ Keyboard navigation in gallery
- 💬 WhatsApp booking/contact buttons
- 📞 Direct call-to-action button
- 📝 Contact form
- 🧭 Responsive navigation bar
- ✨ Scroll-based animations
- 🎨 Centralized CSS color variables
- ♻️ Reusable React components
- 🔁 Dynamic rendering using `.map()`

---

## 🛠️ Tech Stack

This project is built using:

- **React**
- **Vite**
- **Tailwind CSS**
- **React Router**
- **React Icons**
- **React Intersection Observer**
- **Tailwind Merge**
